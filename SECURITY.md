# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to **zeshanshakil0@gmail.com**.
Please do not open a public issue for security reports.

Include where possible: affected version or commit, the impact, and steps to
reproduce.

## Upstream advisories

This product is derived from a third-party AGPLv3 project management platform
(see `UPSTREAM.md`). Security advisories published for that upstream project
apply here. Track upstream releases and apply relevant patches.
